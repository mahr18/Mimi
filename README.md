# Dizi Platform

منصة عربية لاكتشاف المسلسلات التركية، مع أساس قابل للتوسع لعرض المواسم والحلقات وربط المستخدم بمصادر المشاهدة الرسمية والمرخّصة.

> **تنبيه:** العناوين والتقييمات في المكتبة الرئيسية بيانات تجريبية خيالية. يوجد بحث مباشر تجريبي عبر TVmaze للحصول على بيانات تعريفية، وليس لمشاهدة الحلقات.

## ما يعمل في المرحلة الحالية

- واجهة عربية RTL بتصميم داكن ومتجاوب.
- بحث محلي فوري في بيانات العرض التجريبية وتصفية حسب النوع.
- صفحات تفاصيل مستقلة لكل عنصر تجريبي، وصفحات مباشرة للمسلسلات المسترجعة من TVmaze مع المواسم والحلقات.
- بحث مباشر في TVmaze عبر المسار `/api/tvmaze/search?q=...` مع تحقق من طول العبارة، معالجة أخطاء، وذاكرة تخزين مؤقت.
- قسم اكتشاف مباشر للمسلسلات التركية، مع بحث بالاسم يطلب نتائج TVmaze ديناميكيًا ويعرض فقط العناوين التي يصنّف المصدر لغتها بأنها Turkish. البحث مخزّن مؤقتًا لمدة ساعة، وقائمة الاكتشاف الافتراضية لمدة 6 ساعات.
- صفحات مباشرة لتفاصيل المسلسل من TVmaze، مع تجميع الحلقات حسب الموسم وعرض التواريخ والملخصات عند توفرها.
- دليل روابط إلى مواقع رسمية: tabii وKanal D وNOW وNetflix Türkiye. هذه روابط لمواقع الجهات نفسها وليست تأكيدًا بأن مسلسلًا بعينه متاح لديها؛ التوفر والحقوق والاشتراك تختلف حسب العمل والمنطقة.
- إظهار رابط الموقع الرسمي للعمل على بطاقة الاكتشاف وصفحته عند توفره في بيانات TVmaze، وإظهار الموقع الرسمي للقناة/المنصة عند توفره. لا نخمن الروابط المفقودة ولا نعد بتوفر البث.
- أساس أولي للبيانات الوصفية وملفي `robots.txt` و`sitemap.xml`؛ صفحات العناوين الخيالية لا تُفهرس ولا تدخل في خريطة الموقع.
- GitHub Actions للتحقق من TypeScript وبناء المشروع عند الدفع إلى `main` أو فتح Pull Request.

يمكن فتح صفحة تفاصيل أي نتيجة بحث من زر **المواسم والحلقات**؛ المسار الداخلي هو `/tvmaze/{id}` ويستند إلى بيانات TVmaze المحدثة مع تخزين مؤقت لمدة ساعة.

## التشغيل محليًا

يتطلب Node.js 20.9 أو أحدث.

```bash
npm install
cp .env.example .env.local
npm run dev
```

ثم افتح http://localhost:3000.

التحقق والبناء:

```bash
npm run typecheck
npm run build
npm start
```

## النشر التجريبي على Vercel

1. افتح [Vercel](https://vercel.com/) وسجّل الدخول باستخدام GitHub.
2. اختر **Add New → Project**، ثم استورد المستودع `mahr18/Mimi`.
3. اترك إعدادات البناء الافتراضية الخاصة بـ Next.js، ولا تحتاج إلى قاعدة بيانات أو متغيرات سرية في النسخة الحالية.
4. انشر نسخة المعاينة أولًا واختبر الصفحة الرئيسية والبحث وصفحات تفاصيل المسلسلات.
5. بعد اعتماد رابط الإنتاج، أضف متغير البيئة `NEXT_PUBLIC_SITE_URL` بقيمة رابط الموقع الحقيقي الكامل، مثل `https://your-project.vercel.app`، ثم أعد النشر. لا تضع قيمة وهمية ولا تفعّل الفهرسة قبل اعتماد النطاق.
6. اختبر `/robots.txt` و`/sitemap.xml` بعد النشر، وتأكد أن خريطة الموقع تستخدم عنوان الإنتاج الصحيح.

ملف `.env.example` لا يفعّل رابطًا افتراضيًا؛ اترك المتغير غير مضبوط في التطوير والمعاينة حتى تبقى الصفحات غير مفهرسة. تمت إضافة ترويسات أمان أساسية، لكنها لا تغني عن مراجعة أمنية قبل الإطلاق العام.

لا يمكن اعتبار الموقع منشورًا بمجرد رفع الملفات إلى GitHub؛ يجب إكمال الاستيراد والنشر داخل Vercel. لا توجد حاليًا قاعدة بيانات أو تسجيل دخول أو لوحة إدارة أو نظام تشغيل فيديو أو إعلانات. قسم الاكتشاف التركي يدعم البحث المباشر بالاسم لكنه يعتمد على تغطية TVmaze، ولا يُعد فهرسًا شاملًا لجميع المسلسلات التركية.

## مصادر البيانات والترخيص

بحث البيانات المباشر يستخدم [TVmaze API](https://www.tvmaze.com/api). يذكر TVmaze أن واجهة API العامة مرخّصة بموجب CC BY-SA، مع وجوب الإسناد والالتزام بشرط المشاركة بالمثل. راجع الشروط الحالية واطلب مراجعة قانونية قبل استخدام بيانات أو صور خارجية في مشروع ربحي. ظهور رابط أو صورة عبر API لا يمنح حقوق بث المسلسل أو ترجمة الحلقة.

- [TVmaze API documentation](https://www.tvmaze.com/api)
- [TVmaze Terms of Service](https://www.tvmaze.com/site/tos)
- [TVmaze Copyright Policy](https://www.tvmaze.com/site/copyright)

لا يجمع هذا المشروع روابط بث غير مصرّح بها، ولا ينزّل الفيديوهات أو ينسخ الترجمات من مواقع خارجية. لا تضف محتوى أو روابط إلا إذا كان لديك إذن واضح باستخدامها.

## ما لم يُنجز بعد

- قاعدة بيانات وإدارة محتوى آمنة مع صلاحيات دخول.
- مصدر موثوق لبيانات المسلسلات التركية مع سياسة ترخيص مناسبة للاستخدام التجاري.
- ربط كل مسلسل بمزودي المشاهدة المتاحين له بعد التحقق من حقوقه ومنطقته.
- إدارة حقوق المحتوى وسجلّ موافقات قبل نشر روابط مشاهدة.
- اختبارات آلية أوسع ومراجعة أمنية.
- نشر فعلي وربط نطاق والتحقق من نجاح البناء على GitHub Actions.
