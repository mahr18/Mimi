# VIP TV

منصة عربية باسم VIP TV لاكتشاف المسلسلات وعرض بياناتها ومواسمها وحلقاتها، بواجهة RTL متجاوبة.

> **الحالة:** يعتمد الاكتشاف على بيانات TVmaze التعريفية؛ لا تعني هذه البيانات توفر حق بث الحلقات. لا توجد إعلانات مفعّلة. مشغل Qarmzi التجريبي معطّل حتى مراجعة نطاق الإذن.

## ما يعمل في المرحلة الحالية

- واجهة عربية RTL بتصميم داكن ومتجاوب.
- اكتشاف وبحث بالاسم والتصفية حسب النوع اعتمادًا على نتائج TVmaze التي يحدد المصدر لغتها بأنها تركية.
- بحث مباشر في TVmaze عبر المسار `/api/tvmaze/search?q=...` مع تحقق من طول العبارة، معالجة أخطاء، وذاكرة تخزين مؤقت.
- صفحة تفاصيل للمسلسلات المسترجعة من TVmaze، تجمع الحلقات حسب الموسم وتعرض التواريخ والملخصات عند توفرها.
- إظهار رابط الموقع الرسمي للعمل على بطاقة الاكتشاف وصفحته عند توفره في بيانات TVmaze، وإظهار الموقع الرسمي للقناة/المنصة عند توفره. لا نخمن الروابط المفقودة ولا نعد بتوفر البث.
- مصدر واحد مسجّل لمشغل YouTube الرسمي؛ بيانات القناة والتضمين موضحة في [سجل التشغيل](docs/authorized-playback.md). لم يُتحقق من التشغيل الفعلي أو الإتاحة حسب المنطقة.
- مسارات الكتالوج الخيالي القديم لا تعرض بيانات مختلقة؛ المسار `/series/[slug]` يعيد صفحة 404 إلى أن يتوفر مصدر حقيقي.
- أساس أولي للبيانات الوصفية وملفي `robots.txt` و`sitemap.xml`؛ لا تُفهرس الصفحات قبل تحديد عنوان HTTPS العام.
- GitHub Actions للتحقق من TypeScript وبناء المشروع عند الدفع إلى `main` أو فتح Pull Request.

يمكن فتح صفحة تفاصيل أي نتيجة بحث من زر **المواسم والحلقات**؛ المسار الداخلي هو `/tvmaze/{id}` ويستند إلى بيانات TVmaze المحدثة مع تخزين مؤقت لمدة ساعة.

## التشغيل محليًا

يتطلب Node.js 20.9 أو أحدث.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

ثم افتح http://localhost:3000.

التحقق والبناء:

```bash
npm run typecheck
npm run lint
npm run build
npm start
```

ملاحظة: أمر `lint` الحالي يعيد تشغيل TypeScript (`tsc --noEmit`)؛ لا توجد أداة ESLint أو مجموعة اختبارات آلية في المشروع حاليًا.

## النشر التجريبي على Vercel

1. استخدم مشروع Vercel المرتبط بالمستودع إن كان موجودًا؛ لا تنشئ مشروعًا أو نطاقًا جديدًا لمجرد الاختبار.
2. راجع معاينة Pull Request قبل اعتمادها، واختبر الصفحة الرئيسية والبحث وصفحات التفاصيل على الهاتف وسطح المكتب.
3. لا تنشر إلى الإنتاج ولا تغيّر النطاق من هذه الإرشادات وحدها.
4. بعد اعتماد رابط الإنتاج، أضف `NEXT_PUBLIC_SITE_URL` بعنوان HTTPS الحقيقي ثم اختبر `/robots.txt` و`/sitemap.xml`.

ملف `.env.example` لا يفعّل رابطًا افتراضيًا؛ اترك المتغير غير مضبوط في التطوير والمعاينة حتى تبقى الصفحات غير مفهرسة. تمت إضافة ترويسات أمان أساسية، لكنها لا تغني عن مراجعة أمنية قبل الإطلاق العام.

لا يمكن اعتبار الموقع منشورًا بمجرد رفع الملفات إلى GitHub. لا توجد حاليًا قاعدة بيانات أو تسجيل دخول أو لوحة إدارة. الإعلانات، بما فيها AdSense وMonetag، معطّلة حتى اعتماد الناشر وتنفيذ متطلبات الخصوصية والموافقة. قسم الاكتشاف يعتمد على تغطية TVmaze ولا يُعد فهرسًا شاملًا.

## مصادر البيانات والترخيص

بحث البيانات المباشر يستخدم [TVmaze API](https://www.tvmaze.com/api). يذكر TVmaze أن واجهة API العامة مرخّصة بموجب CC BY-SA، مع وجوب الإسناد والالتزام بشرط المشاركة بالمثل. راجع الشروط الحالية واطلب مراجعة قانونية قبل استخدام بيانات أو صور خارجية في مشروع ربحي. ظهور رابط أو صورة عبر API لا يمنح حقوق بث المسلسل أو ترجمة الحلقة.

- [TVmaze API documentation](https://www.tvmaze.com/api)
- [TVmaze Terms of Service](https://www.tvmaze.com/site/tos)
- [TVmaze Copyright Policy](https://www.tvmaze.com/site/copyright)

لا يجمع هذا المشروع روابط بث غير مصرّح بها، ولا ينزّل الفيديوهات أو ينسخ الترجمات من مواقع خارجية. لا تنشر أي فيديو إلا إذا كنت تملك حقوقه أو لديك إذن واضح بالبث. يمكن أتمتة استيراد الحلقات من API أو موجز رسمي يجيز إعادة النشر، وليس نسخ حلقات مواقع أخرى دون تصريح.

## إعداد الإعلانات

لا يحمل التطبيق أي شيفرة إعلانية حاليًا. لا تُعد إضافة معرّفات ناشر وحدها موافقةً أو نظامًا لإدارة الموافقة؛ راجع [متطلبات تحقيق الدخل](docs/monetization-readiness.md) قبل إعادة تفعيل أي شبكة.

## ما لم يُنجز بعد

- قاعدة بيانات وإدارة محتوى آمنة مع صلاحيات دخول.
- مصدر موثوق لبيانات المسلسلات التركية مع سياسة ترخيص مناسبة للاستخدام التجاري.
- مستندات ترخيص تحدد نطاق استخدام الفيديو وتضمينه والمناطق قبل تسجيل مصدر إضافي.
- نظام موافقة خصوصية معتمد قبل إعادة تفعيل الإعلانات.
- اختبارات آلية مستقلة ومراجعة أمنية؛ لا يوجد حاليًا إطار اختبارات في المستودع.
- فحص المعاينة عبر Vercel بعد إصلاح صلاحية اتصال Vercel؛ لم يُجرَ نشر إنتاجي.

## الحالة

هذه نسخة تطوير أولية. تحقّق من GitHub Actions ورابط المعاينة قبل اعتماد التغيير، ولا يُعد المشروع موقعًا منشورًا حتى يعتمد المالك الإنتاج والنطاق.


## مراجعة مصدر تشغيل قبل تسجيله

تعرض صفحات TVmaze بيانات تعريفية فقط. سجل التشغيل يحتوي مشغلًا واحدًا من YouTube على قناة مرتبطة باسم المسلسل؛ هذا يثبت مصدر الناشر وتقنية التضمين، ولا يُعد رأيًا قانونيًا أو ضمانًا للتوفر التجاري أو الجغرافي.

بعد الحصول على إذن مكتوب يغطي الاستخدام المقصود، تحقق من المنطقة والتضمين. أضف الأصول HTTPS الدقيقة إلى `PLAYBACK_EMBED_ORIGINS` أو `PLAYBACK_MEDIA_ORIGINS`، ثم راجع سجل الحلقة في `lib/authorized-playback.ts` وأضف دليل المصدر وملاحظات الإتاحة وتاريخ المراجعة. اختبر CSP والتضمين والترجمة مع المزود قبل التفعيل. علامة مراجعة المصدر في الكود لا تمنح الحقوق ولا تثبتها قانونيًا؛ بيانات TVmaze أو وجود مشغل لدى طرف آخر لا تثبت حق إعادة البث.

يوجد مصدر واحد فقط: الحلقة الأولى من Kara Sevda عبر مشغل YouTube Privacy Enhanced. فُحصت قائمة قناة Ay Yapım الرسمية وبيانات oEmbed، لكن لم يُختبر التشغيل داخل متصفح فعلي، وقد يقيّد YouTube الإتاحة أو التضمين أو الترجمة. التفاصيل في [سجل مزودي التشغيل](docs/authorized-playback.md).

المسار `/watch/yeralti-17` يعرض تنبيهًا بدلًا من المشغل التجريبي السابق. لم نُبقِ تضمين AnaPlayer/Qarmzi أو أي جلب أو نسخ آلي لمحتوى الموقع؛ لا يُعاد تفعيل ذلك قبل مراجعة إذن موثق يشمل الحلقة ومصدرها والمنطقة والتضمين والاستخدام التجاري.
