# Dizi Platform

منصة عربية لاكتشاف المسلسلات التركية، مع بنية قابلة للتوسع لعرض المواسم والحلقات وربط المستخدم بمصادر مشاهدة رسمية ومرخّصة.

> **تنبيه:** العناوين والتقييمات الموجودة حاليًا بيانات تجريبية خيالية لتطوير الواجهة، وليست دليلًا على وجود أعمال حقيقية أو مصادر بث.

## المرحلة الأولى

- واجهة عربية RTL بتصميم داكن ومتجاوب.
- بحث فوري بالعنوان العربي أو الأصلي والتصنيف.
- تصفية حسب النوع.
- بطاقات مسلسلات وصفحات تفاصيل مستقلة.
- أساس أولي للبيانات الوصفية وSEO.
- توضيح حالة الترخيص قبل إضافة روابط مشاهدة.

## التشغيل محليًا

يتطلب Node.js 20.9 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000.

لإنشاء نسخة إنتاجية:

```bash
npm run build
npm start
```

## الخطوات التالية

1. التحقق من البناء وإصلاح الأخطاء.
2. إضافة قاعدة بيانات وإدارة محتوى آمنة.
3. اختيار مزود بيانات يسمح بالاستخدام المقصود والتحقق من شروط الترخيص ونسب الصور.
4. إضافة المواسم والحلقات وروابط رسمية فقط.
5. إضافة اختبارات وتوثيق متغيرات البيئة قبل النشر.

## الحقوق والسلامة

لا يجمع هذا المشروع روابط بث غير مصرّح بها، ولا ينزّل الفيديوهات أو ينسخ ترجمات أو صورًا من مواقع خارجية. لا تضف محتوى أو روابط إلا إذا كان لديك إذن واضح لاستخدامها. توفر البيانات عبر API لا يعني تلقائيًا السماح باستخدامها التجاري.

## الحالة

المرحلة الأولى نموذج واجهة أمامية يعتمد بيانات محلية تجريبية. لم يتم إعداد قاعدة بيانات أو حسابات أو نظام تشغيل فيديو أو إعلانات بعد. لم يتم تشغيل البناء أو الاختبارات في بيئة تنفيذية ضمن هذه الخطوة.
