## ترتيب التنفيذ

- **P0:** حماية الأسرار، تعطيل مشغل AnaPlayer الخارجي، وعدم تحميل الإعلانات دون الموافقات اللازمة. نتائج البحث المتزامنة لا تستبدل بعضها، وفشل كل استعلامات الاكتشاف يُعرض كخطأ بدل قائمة فارغة.
- **P1:** تثبيت التبعيات، تحسين تفاصيل الحلقات، وضبط metadata والفهرسة على نطاق معتمد. يلزم اختبار الاستخدام المرئي على هاتف حقيقي.
- **P2:** اختيار قاعدة بيانات ومصدر بيانات مناسب للترخيص، ثم حسابات ومفضلة متزامنة ومزود تشغيل بمستندات وحقوق ونطاقات تشغيل مؤكدة.
- **P3:** توصيات مبنية على بيانات حقيقية، قياس يحترم الخصوصية، ولوحة تحرير وتشغيل بعد تأسيس التخزين والصلاحيات.

## حدود التحقق

هذه المراجعة ليست تدقيقًا قانونيًا أو ضمانًا أمنيًا. بيانات TVmaze العامة تخضع لـ CC BY-SA؛ يجب فحص الإسناد والمشاركة بالمثل وحقوق الصور قبل الاستخدام التجاري. لا يمنح مصدر البيانات حق بث الحلقات. فحص npm يخص lockfile في نسخة العمل. لا تتوفر في هذا الاتصال صلاحية قراءة إعدادات Vercel أو متغيراتها.
