## ترتيب التنفيذ

- **P0:** حماية الأسرار، إيقاف أي ادعاء تشغيل غير متحقق، إصلاح أخطاء البناء أو الروابط. تم تشديد تجاهل الملفات وحدود API وإزالة إشارات الواجهة إلى الأكثر بحثًا/الجديد غير المسندة؛ لا توجد خدمة بث متحققة.
- **P1:** تثبيت التبعيات، تحسين اكتشاف المسلسلات والبحث وRTL، وضبط metadata والفهرسة على نطاق معتمد. تم إنجاز lockfile وتحسينات API وSEO المحددة أعلاه. يلزم مزيد من اختبار الاستخدام المرئي على الهاتف.
- **P2:** اختيار قاعدة بيانات ومصدر بيانات مناسب للترخيص، ثم حسابات ومفضلة متزامنة ومزود تشغيل بمستندات وحقوق ونطاقات تشغيل مؤكدة.
- **P3:** توصيات مبنية على بيانات حقيقية، قياس يحترم الخصوصية، ولوحة تحرير وتشغيل بعد تأسيس التخزين والصلاحيات.
